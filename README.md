# Surender Verma — Personal Website

A responsive static website for Surender Verma, covering digital marketing, website development, lead generation, automation and digital safety awareness.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- Static deployment on GitHub + Vercel

## Deploy
Import this repository into Vercel as a static site. Keep all HTML partials and assets in the repository root. No build command is required.

## Configuration
Edit `config.js` to update brand, contact and domain details.

## Contact form
The current form uses `mailto:` to prepare an email in the visitor's default mail app. It is not a server-backed form.

## Accuracy
Capability cards describe service categories and are not represented as verified client case studies. Add confirmed examples and metrics only when they are accurate and approved for publication.
