- work.html        Capability examples (not fabricated client case studies)

IMPORTANT CONTACT SETTINGS
Open config.js to edit email, WhatsApp number, phone number, website URL and brand text.
WhatsApp format: country code + number, digits only. Do not include +, spaces or dashes.
The supplied details have been carried forward from the files you uploaded. Verify them before publishing.

GITHUB + VERCEL DEPLOYMENT
1. Keep all files in the same root folder of the repository.
2. Upload/commit the files to GitHub.
3. In Vercel, import the GitHub repository.
4. This is a static HTML/CSS/JavaScript site. No build command is required.
5. Set the output directory to the repository root (usually leave the default for a static project).
6. Deploy. Every new push to the connected branch should trigger a deployment.

LOCAL PREVIEW
Because header.html and footer.html are loaded using fetch(), do not test by double-clicking index.html.
Run a local static server from the project folder, for example:
  python -m http.server 8000
Then open http://localhost:8000

CONTACT FORM LIMITATION
The form opens the visitor's default email app with a prefilled message using mailto:.
It does not submit to a server or guarantee delivery. If you want an on-site form, connect a form provider or backend later.

CONTENT INTEGRITY
The website avoids presenting invented client names, testimonials, performance metrics or project results as real.
Add genuine case studies only after verifying the details and obtaining permission where needed.

BEFORE PUBLISHING
- Verify email, phone, WhatsApp and domain in config.js.
- Check every page on desktop and mobile.
- Test the mobile menu, search, theme toggle, contact links and form.
- Add a real profile photo and social profile links if desired.
- Confirm that all service descriptions and any public claims accurately reflect your current offerings.
