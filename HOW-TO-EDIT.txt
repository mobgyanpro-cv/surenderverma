--------------------------------------------------------------------------------
1. Place your photo inside the "images" folder.
2. Name the file: "surender.jpg"
3. The website will immediately load your picture in the hero section!
   (If the photo is missing or has a different name, a clean SVG placeholder
   displays automatically without broken image icons).

4. HOW TO CUSTOMIZE PLACEHOLDERS IN HTML FILES
--------------------------------------------------------------------------------
Every customizable block has an HTML comment starting with <!-- PLACEHOLDER: ... -->
- In index.html: Testimonial names and feedback in the dark section.

- In awareness.html: Verification of local cybercrime reporting details.

5. HOW TO UPLOAD TO WEB HOSTING
--------------------------------------------------------------------------------
This website is 100% static (pure HTML, CSS, JavaScript) with ZERO build tools,
zero node_modules, and zero npm commands needed!
You can directly upload all files to:
- Vercel (drag and drop the folder or connect via GitHub)
- Netlify (drag and drop into Netlify Drop)
- GitHub Pages (push code and enable Pages in repository settings)
- Hostinger, GoDaddy, Namecheap, cPanel (upload all files to public_html)
